## Project

### Contact Manager

The Contact Manager project is a Java Servlet-based web application developed using Maven and Apache Tomcat.

### Features Implemented

- Create/Add Contact
- View Contacts
- Edit/Update Contact
- Delete Contact
- Servlet-based request handling
- Maven project configuration
- WAR packaging and deployment on Apache Tomcat

## Technologies Used

- Java
- Jakarta Servlets
- Maven
- Apache Tomcat
- HTML
- VS Code
